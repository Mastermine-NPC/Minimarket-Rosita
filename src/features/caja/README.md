# Caja Rosita

Implementada en `/caja`: CashCatalog/CameraScanner, CashShiftPanel, CashHistory y SaleReceipt, compuestos con UI y tokens existentes. Controlador en pages/cash-page.tsx, transacciones en lib/operations.ts, esquemas/migración en lib/operations-schema.ts y storage.ts. Precios/stock compartidos con tienda; borrador por agente separado del carrito. CardSimulation se reutiliza. Sin backend ni pago real. Ver docs/OPERACIONES-1.0.0.md para permisos, guiones, códigos y límites.
