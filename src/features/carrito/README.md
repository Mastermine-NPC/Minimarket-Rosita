# Carrito · 0.4.0

CartContent se reutiliza en CartSheet y CartPage. useCart/priceCart calculan líneas, contador y subtotal desde catálogo e inventario compartidos. Context/useReducer persiste cantidades. Agregar no reserva ni descuenta. Desactivados o stock insuficiente permanecen explicados y bloquean la confirmación; el usuario puede corregir o eliminar. Checkout requiere cliente de demostración; confirmar pedido descuenta y genera movimientos juntos y una sola vez.
