# Ilustraciones locales originales

Seis SVG dibujados como código para este prototipo. No usan fotografías, logotipos ni recursos gráficos externos. Se permite su reutilización con el código de Rosita. Representaciones genéricas de demostración: no describen el envase o aspecto exacto de Oreo, Colgate u otros productos. Se muestran con la etiqueta «Ilustración · sin fotografía». Las fotografías reales siguen pendientes.
