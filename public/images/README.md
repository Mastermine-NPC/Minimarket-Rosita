# Imágenes locales de Rosita

Se conservan rosita-logo.png, negocio-rosita.jpg y productos-rosita-atlas.jpg del material del usuario/prototipo previo. El atlas contiene 18 fotos recortadas mediante CSS.

Desde 0.4.0 se añaden seis SVG originales de código en illustrations, identificados «Ilustración · sin fotografía». Son representaciones genéricas; las seis fotos reales siguen pendientes. No se descargaron imágenes externas ni se incluyen marcas gráficas nuevas. Procedencia y límites en docs/RECURSOS.md y illustrations/README.md.
